# Portfolio Creativo - Nicolas Basilico

Bienvenido al repositorio de mi portafolio profesional. Este proyecto es una aplicación Full Stack moderna diseñada para mostrar mis trabajos, habilidades y trayectoria profesional.

## 🚀 Tecnologías

### Frontend
- **React**: Biblioteca principal para la interfaz de usuario.
- **Vite**: Herramienta de compilación rápida y moderna.
- **Tailwind CSS**: Framework de utilidad para estilos y diseño responsivo.
- **Framer Motion**: Librería para animaciones fluidas y transiciones.

### Backend
- **.NET 9 (C#)**: API robusta y de alto rendimiento.
- **ASP.NET Core Web API**: Manejo de rutas y controladores.
- **MailKit**: Servicio para el envío seguro de correos electrónicos (Gmail SMTP).
- **Docker**: Contenerización para facilitar el despliegue.

## ✨ Características

- **Diseño UI/UX Premium**: Interfaz oscura, elegante y con animaciones suaves.
- **Navegación Fluida**: Transiciones entre páginas y componentes interactivos.
- **Formulario de Contacto Real**: Conectado al backend para enviar correos directamente a mi Gmail.
- **Responsive**: Adaptado perfectamente a móviles, tablets y escritorio.
